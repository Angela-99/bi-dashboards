# BI Dashboards

Dashboards built in Power BI, with Tableau dashboards to follow. All projects are school projects.

## Power BI

| # | Project | Data | Highlights |
|---|---------|------|------------|
| 1 | [Sales Performance Dashboard](powerbi/01-sales-performance-dashboard) | Adventure Works sales | Time intelligence DAX, YoY growth, rolling revenue, forecast |
| 2 | [Walmart PESTEL Analysis](powerbi/02-walmart-pestel-analysis) | Walmart weekly store sales | PESTEL framework, risk scoring, scenario analysis, Python visual |
| 3 | [Housing Price Regression](powerbi/03-housing-price-regression) | 545 house listings | Outlier analysis, log transform, regression with R visuals |
| 4 | [Smartphone Market Analysis](powerbi/04-smartphone-market-analysis) | Kaggle smartphones dataset | Star schema, DAX feature adoption measures, 6 dashboard pages |
| 5 | [Mobile Sales Forecasting](powerbi/05-mobile-sales-forecasting) | Synthetic transaction data | Star schema, exponential smoothing forecast, what-if price simulation |

## How to open the dashboards

Download the `.pbix` file in a project folder and open it in Power BI Desktop (free, Windows). Each project folder also has a README and preview images where available.
